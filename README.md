# 信号轮盘 · 海克斯工作台 v2

透明置顶的 Windows 桌面工具，保留《英雄联盟》12.21 经典四向信号和五格表情原图，加入自定义按键、可选海克斯细线装饰与演示标注。

双击 **`PingTurntable.exe`** 或 **`启动轮盘.cmd`** 运行。不需要安装 Python、Node.js 或 NuGet 包，使用 Windows 自带的 .NET Framework 4.x。请保留同目录的 `assets` 文件夹。

## 自定义按键

打开设置的 **「自定按键」** 页，点击想修改的按键框，然后按下新组合键。也可以在录制窗口的指定区域点击中键或鼠标侧键，支持 Ctrl、Alt、Shift 搭配键盘或鼠标。

- 信号和表情：按住配置的主键或鼠标键，拖动选择，释放主键发送；表情轻按发送中央格。
- 其他操作：按一次执行。
- 左键和右键须搭配修饰键，避免占用所有普通点击；中键和鼠标侧键可单独绑定。
- Esc 用于取消当前轮盘或取消录制，不能作为新绑定。
- 每项可停用，也可以恢复默认键位。保存立即生效，旧绑定会释放。
- 重复组合或被 Windows 其他程序注册的键位会提示冲突，并保留原来的可用配置。鼠标侧键和其他程序的底层鼠标绑定无法由 Windows 注册机制检测。
- 单独字母会被全局占用；暂停后信号键释放，恢复键和设置键仍有效。录制窗口离开前台后，不会把其他窗口的键入录成新按键。

## 默认操作

| 操作 | 默认键位 |
| --- | --- |
| 信号轮盘 | Alt + 左键，按住拖动并释放左键 |
| 表情轮盘 | Alt + T，按住移动后释放 T |
| 方向 | 上：危险；右：正在路上；下：协助我；左：敌人不见了 |
| 取消 | Esc 或右键；信号在中央释放也会取消 |
| 暂停 / 恢复 | Ctrl + Alt + P；被占用时自动尝试 Ctrl + Alt + Shift + P |
| 打开设置 | Ctrl + Alt + O，或双击托盘图标 |
| 切换常驻信号 / 表情 | Ctrl + Alt + E |
| 显示 / 隐藏常驻轮盘 | Ctrl + Alt + H |
| 静音 / 开启声音 | Ctrl + Alt + M |
| 在鼠标处重放上次标记 | Ctrl + Alt + Shift + R |
| 清除所有屏幕标记 | Ctrl + Alt + Backspace |
| 直接发送四种信号 | Ctrl + Alt + 1 / 2 / 3 / 4 |
| 移动常驻轮盘 | Shift + 左键拖动；开启位置锁定后不可拖动 |

**以设置中显示的当前绑定为准。** 启动时发生系统占用的项可能暂时停用，可通过按键录制重新设置；托盘菜单始终可用。

## 新增外观与实用功能

- **海克斯微光**：只在原轮盘外围加金色细线、细小刻度与轻微光晕。外观页可以切回经典原版，完整关闭新增装饰。
- **待机透明度**：常驻轮盘移开鼠标后变淡，悬停时恢复清晰。
- **减少动态效果**：减弱弹跳和扩散运动，保留淡出反馈。
- **演示标注**：信号和表情可附文字说明；停留时间可设为 0.8–6 秒。
- **最近 8 次标记**：点击列表中的「重放」，在原位置再次显示；左侧快捷按钮也可重放上次标记。重放快捷键在鼠标当前位置显示。
- **一键静音、清除标记、锁定位置、位置重置**，以及原有 60%–180% 缩放、独立音量和 15 个旧版表情的五格配置。

设置、按键、常驻模式、暂停状态和位置自动保存在本目录 `settings.json`。最近标记列表仅在内存中保存，重启后清空；诊断日志 `runtime.log` 会保留发送类型和位置，不记录键入文字、不上传日志。应用本身不访问网络。

关闭设置窗会收起到托盘。完全退出请使用托盘菜单。普通桌面及窗口/无边框全屏可用；独占全屏和 Windows 安全桌面不保证显示。

这是**本机桌面标记工具**，不会向游戏队友、聊天软件或其他电脑发消息。录制整个桌面或共享屏幕时，可将这些标记一起录入。

## 还原与创作的边界

轮盘原始贴图、图标位置、方向布局和表情资源固定到 12.21。经典外观已与上一版本做像素比较，确认未改变。海克斯外框、工作台和文字标注是本工具的新设计，不冒充游戏原版。

英文加载同版 Beaufort 字体；中文字体、桌面粒子和动画仍有适配差异，音效未与 12.21 音频库逐样本比对。因此不能宣称所有动态表现逐帧一比一。详细来源见 [SOURCES.md](SOURCES.md)。

## 开发与验证

```powershell
.\build.ps1
.\PingTurntable.exe --self-test
```

`src` 保存完整 C# 源码，无额外库依赖。自检覆盖快捷键迁移、组合重复、外部占用、失败回滚、暂停释放、鼠标侧键解析、素材 SHA-256、原版外观像素回归、透明绘制与海克斯标注。报告与预览在 `verification` 下。`verification/live-input.json` 记录本次实际窗口测试范围。

`tools/fetch_assets.py` 仅供开发时重新下载历史资源，需 Python、requests、Pillow。`PingTurntable.exe --quit` 可正常退出当前运行实例。
